# GOBKINEMATICS v0.1.0

## Initial Experimental Release

GOBKINEMATICS is a Python library for the graphical representation and kinematic classification of geological faults.

### Current capabilities
- Structural fault data representation.
- Kinematic classification and visualization.
- Complete and compact representation modes.
- STRIKE, FAULT and AUX graphical customization.
- Optional connectors between STRIKE and FAULT.
- Integration with Matplotlib.

### Purpose of this release

This is an experimental prototype intended for evaluation by geologists and researchers working in structural geology.

Feedback, suggestions, bug reports and recommendations for future implementations are welcome.

### Development status

This project is under active development. Additional features, documentation, data import tools and report generation will be incorporated in future releases.
